Tacitum / Adverse media

Adverse media, sold on Telegraph.

Telegraph had no miner for adverse-media screening, so we built one. It returns headlines from the last twelve months that name the company and report something adverse, each with its source and date. It is registered on Telegraph, and every Tacitum assessment buys from it.

How it screens

Precise enough for a compliance file.

Twelve months

The entity plus adverse terms, searched in GDELT and Google News over the last year.

Named in the headline

A headline must name the company and report something adverse, or it is dropped.

Categorised

Fraud, laundering, sanctions, bribery, regulatory action, litigation, criminal, probes, insolvency, breaches, misconduct.

Right company only

Case-sensitive names and same-clause terms: "Meta fined, Binance resumes" is not about Binance. Victims, own anti-fraud work and routine merger reviews do not count.

Measured quality

Scored on headlines it had never seen.

We labelled real headlines by hand, tuned on one set, checked on a second, then froze the rules and scored a third set collected afterwards and labelled blind. Only that last number is a fair estimate, so it is the one we lead with.
