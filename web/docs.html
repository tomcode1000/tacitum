Overview

Tacitum buys counterparty intelligence through Telegraph without revealing who was screened or who asked. It has four parts:

  • Assessment workflow: sanctions from two miners, the company registry from two independent registers, regulatory filings and adverse news, written up as a memo with a verified receipt for every answer.
  • Decoy engine: the real company is bought among matched decoys, shuffled and spaced, with privacy measured against attackers.
  • Screened pool: a Sepolia contract that admits only deposits whose depositor passed Telegraph sanctions screening, and funds one-time payers through a Groth16 withdraw.
  • Adverse-media miner: a Telegraph provider (Track 1) that Tacitum buys its news check from.

Get test funds

npm run wallet       # creates PRIVATE_KEY if empty, prints balances
# send ~0.01 Sepolia ETH to the printed address, then run it again to mint 10 test USDC
npm run wallet
npm run first-call   # one paid $0.01 sanctions screen, to prove the path works

Run an assessment (no privacy)

The baseline: what a desk would get on Telegraph today, fully public.

npm run assess -- "Barclays PLC" GB

The memo is written to assessments/ as Markdown and JSON. Each answer's signal hash is re-checked against /engine/v1/signal/{hash}.

Private assessment

# one-time payer funded by your wallet (fast to try; the funding is linkable)
npm run private -- "Barclays PLC" GB 4

# one-time payer funded by the screened pool (the desk never appears)
npm run private -- "Barclays PLC" GB 4 --pool

The last argument is the number of parties in the bundle, real one included. Expect 5 to 8 minutes: the payer must wait about two minutes after funding before Telegraph sees its balance, and receipts take a few minutes to publish.

Pool mode needs an approved note. Deposit and get screened first (next section). Each --pool run spends one note.

Screened pool

The pool is already deployed; its address is in data/pool.json. To deposit and get approved:

# seed N screened deposits, one of them yours, and keep your note unspent
node scripts/pool-e2e.mjs 4 --deposit-only

# screen anything still pending (one pass, or keep watching)
npm run pool:screen
npm run pool:screen -- --watch

A deposit is approved only when Telegraph's sanctions screen returns a clear answer. A match is refunded. An empty answer leaves it pending until the next pass. To deploy your own pool: npm run pool:deploy -- 1 (denomination in USDC).

Library

import { tacitum } from "tacitum";
import { privateKeyToAccount } from "viem/accounts";

const funder = privateKeyToAccount(process.env.FUNDER_KEY);
const relayer = privateKeyToAccount(process.env.RELAYER_KEY); // no link to the funder

const t = tacitum({ funder, k: 4, pool: { relayer } });
await t.deposit();                                    // join the pool
const { memo } = await t.assess({ name: "Barclays PLC", jurisdiction: "GB" });

// any intent, with your own decoys
const { answer } = await t.ask("SANCTIONS_SCREENING_MATCH_GENERAL", { name: "Acme Ltd" },
  { decoys: [{ name: "Brindle Ltd" }, { name: "Corvel Ltd" }, { name: "Dunmore Ltd" }] });

Without pool, payers are funded straight from the funder. In pool mode the library refuses to use the funder as relayer, because that would link the withdraw to the desk.

Adverse-media miner

The miner is a small HTTP service (miner/) described to Telegraph by miner/public/miner.yaml. It is registered as tacitum-adverse-media (id 7314402) for NEWS_SEARCH_GENERAL.

# try the service locally
node --input-type=module -e "const {screen}=await import('./miner/lib/adverse.js');console.log(await screen('Barclays PLC'))"

# host your own copy, then register or update it on Telegraph
cd miner && vercel deploy --prod
node scripts/miner-register.mjs --dry     # simulate first
node scripts/miner-register.mjs           # swaps test USDC for the MACHINA bond, then registers
node scripts/miner-update.mjs             # after changing the YAML

Through Telegraph, ask it directly with miner id 7314402 and params { "query": "Barclays PLC" }. Each answer costs $0.01.

Quality

node miner/eval/run.mjs     # tuning, holdout and blind test sets; free and offline

On 63 blind-labelled headlines from 8 companies it was never tuned on: precision 0.91, recall 0.71, F1 0.80. The labelling guide, all three sets and the known misses are in miner/eval/; the miner's own submission document is miner/README.md.

Contracts and circuit

  • contracts/ScreenedPool.sol: deposits, screening approvals with the Telegraph signal hash, Poseidon Merkle tree (depth 16), Groth16 withdraw into Telegraph escrow.
  • circuits/withdraw.circom: 9,255 constraints; binds recipient, relayer and fee into the proof.
  • Rebuild: circom circuits/withdraw.circom --r1cs --wasm -o build/circuits, then a Groth16 setup with snarkjs. The shipped key comes from a local Powers of Tau and is for testnet only.

Troubleshooting

SymptomCause and fix
Every call refused with "insufficient escrow"Telegraph had not yet seen the new payer's balance. The scripts wait two minutes after funding; if you call sooner the payer stays refused until the epoch closes.
"pruned history unavailable"Your RPC drops old logs. Set LOGS_RPC_URL to an archive-capable endpoint.
Memo shows 0 receipts verifiedSignals take a few minutes to publish. Run node scripts/rerender-memo.mjs on the memo's JSON.
A deposit stays pendingThe sanctions screen returned no clear answer. Run npm run pool:screen again.
Miner answers slowly or from one sourceGDELT rate-limits shared cloud IPs; the miner falls back to Google News. A host with its own IP fixes it.
